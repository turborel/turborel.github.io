Well, this is the genesis of something I believe will be *great* for the future of storage infrastructure. The Turborel blog is where I and others associated with the project will write about it.

If you haven't heard of it, Turborel (TUR-boh-rel) is an open-source relational database system written in Rust. You can embed it as a library, or run it as a server and query it in SQL with its command-line client.

You can read more about Turborel and how to use it in the [documentation](/docs/) . It's built from the `doc/` folder of the repository and is split into several volumes. Until the first release, it tracks `main` and is marked *alpha*.

Follow along by subscribing to the [Atom feed](/blog/feed.xml) or the newsletter, and watch the [repository](https://github.com/turborel/turborel) for releases.
