turborel (TUR-boh-rel) is a relational database system written in Rust. Embed it as a library, or run it as a server, `turboreld`, for many clients at once, and query it in SQL with `turborel`, its command-line client.

This blog is where we'll write about releases benchmark analysis, design decisions and how the parts fit together.

## Reading the manuals

The [documentation](/docs/) is built from the `doc/` folder of the repository, in five volumes: the User's Guide, the SQL Reference Manual, the Operator's Guide, the Client Reference and the Appendices. Until the first release it follows `main`, marked *alpha*; each release then gets its own version in the menu at the top of the sidebar.

## Following along

Subscribe to the [Atom feed](/blog/feed.xml) or the newsletter, and watch the [repository](https://github.com/turborel/turborel) for releases.
